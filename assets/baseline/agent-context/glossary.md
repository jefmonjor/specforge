# Glosario Corporativo y Lenguaje Ubicuo

- **SDD (Spec-Driven Development):** Metodología donde la especificación BDD en Gherkin es la única fuente autoritativa de la verdad y guía el ciclo de vida completo.
- **TDD (Test-Driven Development):** Ciclo continuo Red -> Green -> Refactor donde ninguna línea de código se escribe sin un test previo en fallo.
- **YAGNI (You Aren't Gonna Need It):** Principio de diseño que prohíbe implementar funcionalidades "por si acaso".
- **KISS (Keep It Simple, Stupid):** Búsqueda de la solución más sencilla, legible y mantenible posible.
- **CodeGraph:** Grafo semántico y mapa estructural del repositorio analizado en memoria para navegación quirúrgica.
- **ADC (Application Default Credentials):** Esquema de autenticación sin llaves fijas que hereda la identidad de Google Cloud SDK.
- **MDCMS / MDOpen:** Herramientas y sistemas de gestión de cambios y despliegue en entornos IBM i / AS400.
- **GitOps:** Paradigma donde el repositorio Git es la única fuente de verdad declarativa para despliegues (Tekton / OpenShift).
- **Probes de Salud (/health e /info):** Sondas de observabilidad en la raíz para balanceadores de carga y Kubernetes, con HTTP 200 y JSON limpio.
