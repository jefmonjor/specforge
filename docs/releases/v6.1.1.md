SpecForge 6.1.1 is a maintenance release: nothing changes in how SpecForge behaves.

## Install

```bash
go install github.com/jefmonjor/specforge/v6@latest
```

or download a binary:

```bash
R=https://github.com/jefmonjor/specforge/releases/download/v6.1.1
F=specforge-darwin-arm64   # or darwin-amd64, linux-amd64, linux-arm64
curl -LO $R/$F && curl -LO $R/checksums.txt
sha256sum -c checksums.txt --ignore-missing   # macOS: shasum -a 256 -c …
chmod +x $F && sudo mv $F /usr/local/bin/specforge
specforge version
```

On Windows, download `specforge-windows-amd64.exe`, rename it to `specforge.exe` and put it in a folder on your `PATH`.

## What changed

- **`go install` works.** The module is now `github.com/jefmonjor/specforge/v6`, as Go requires for a v6 tag, and `specforge version` shows the version and commit Go recorded.
- **Dead code removed:** five functions nothing called.
- **Issue and pull request templates**: the bug report asks for `specforge version` and `specforge doctor`; vulnerabilities go to a private advisory.
- **The design plans moved to `docs/history/`**, with a note on what they are.

**Full changelog**: https://github.com/jefmonjor/specforge/compare/v6.1.0...v6.1.1
