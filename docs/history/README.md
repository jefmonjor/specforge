# Design history

These are the plans SpecForge was built from, kept as a record of why it works the way it does. They are written in Spanish and describe intentions at the time; where the code differs, the code and the [user guide](../../USER_GUIDE.md) are right.

- [IMPROVEMENT_PLAN.md](IMPROVEMENT_PLAN.md): the audit of v3 and the phases from v4 to 6.1, with what each real run found.
- [V6_PLAN.md](V6_PLAN.md): the design of SpecForge 6 (proportional review, verifiable lenses, operational safety).

The changes in each release are in [docs/releases/](../releases/).
