# Security Policy

## Supported Versions

Only the latest release of SpecForge receives active security updates and vulnerability patches.

| Version | Supported          |
| :---    | :---               |
| 6.x     | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability

We take the security of SpecForge and the developers using it very seriously.

If you discover a security vulnerability in SpecForge:

1. **Do not disclose the vulnerability publicly** in a public issue, discussion, or pull request.
2. Please submit a private security advisory through **GitHub Security Advisories** on the repository page:
   `https://github.com/jefmonjor/specforge/security/advisories/new`
   or report via email to the maintainers at `security@jefmonjor.dev`.
3. Provide detailed steps to reproduce the issue, including:
   - Command used and arguments
   - Platform (OS, architecture, Go version)
   - Sample inputs or files triggering the issue
   - Assessment of potential impact

### Response Timeline
- **Initial Response:** Within 48 business hours confirming receipt of report.
- **Triage & Assessment:** Within 7 calendar days with severity classification.
- **Patch & Release:** Coordinated security patch released with public advisory credits.
